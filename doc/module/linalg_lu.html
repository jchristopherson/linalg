  • private pure subroutine csr_lu_factor(a, lu, ju, droptol, flag)

    Builds incomplete LU factors using SPARSKIT ILUT. These approximate factors are intended for preconditioning, not an exact direct solve. A detected zero pivot retains the legacy NaN-valued factor output.

    Arguments

    Type IntentOptional Attributes Name
    class(csr_matrix), intent(in) :: a

    Nonempty square CSR matrix, copied into neither dense storage nor A. Storage must be valid with unique column indices within each row.
    type(msr_matrix), intent(out) :: lu

    Combined incomplete factors in MSR format, with inverse U diagonal. Not usable when FLAG reports an error.
    integer, intent(out), dimension(:) :: ju

    Caller-owned N-element array receiving upper-factor row pointers.
    real(kind=real64), intent(in), optional :: droptol

    Finite nonnegative ILUT drop tolerance; default SQRT(EPSILON). Zero disables threshold dropping, but the per-row fill cap remains.
    integer, intent(out), optional :: flag

    LA_NO_ERROR on success. Validation returns the statuses documented by VALIDATE_CSR_FACTOR_INPUT; incorrect JU size returns LA_MATRIX_DIMENSION_ERROR. ILUT breakdown returns LA_SINGULAR_MATRIX_ERROR, LA_MATRIX_FORMAT_ERROR, or LA_INVALID_OPERATION_ERROR. When omitted, validation and format errors use ERROR STOP; a zero pivot retains the legacy NaN output.

  • private pure function csr_lu_solve(lu, ju, b) result(x)

    Applies the combined triangular factors with SPARSKIT LUSOL. If the factors came from ILUT, this solves the incomplete-factor system only; use PGMRES_SOLVE or SPARSE_LU_FACTORIZATION for the original CSR system. Malformed factors use ERROR STOP; singular/nonfinite factors yield NaNs.

    Arguments

    Type IntentOptional Attributes Name
    class(msr_matrix), intent(in) :: lu

    Nonempty square MSR factors, with inverse U pivots on the diagonal.
    integer, intent(in), dimension(:) :: ju

    N pointers splitting each row into strict lower and upper entries.
    real(kind=real64), intent(in), dimension(:) :: b

    Finite N-element right-hand side, not modified.

    Return Value real(kind=real64), allocatable, dimension(:)

    N-element solution of the factor system. Singular/nonfinite factors yield NaNs, preserving legacy propagation. No GMRES refinement occurs.

type, public, extends(matrix_factorization) ::  sparse_lu_factorization

Owns a real CSR system and an ILUT preconditioner. SOLVE and SOLVE_IN_PLACE solve the original A * X = B using restarted GMRES; they do not merely apply the incomplete factors. This is an iterative solver, not a pivoted sparse direct LU factorization. FACTOR prepares the preconditioner explicitly, or solves prepare it lazily. UPDATE invalidates it. No dense matrix copy is formed. Errors return through optional FLAG arguments; if omitted, errors terminate with ERROR STOP. No inverse or determinant is provided.
