type, public, extends(linear_operator) :: csr_operator

Read-only operator owning a validated CSR copy. Construction copies storage once; subsequent applications neither copy nor densify A.


Constructor

public interface csr_operator

Constructs an owned operator from validated finite CSR storage.

  • private pure function csr_op_init(a) result(rst)

    Copies a CSR matrix after validating its storage. Does not factor it.

    Arguments

    Type IntentOptional Attributes Name
    class(csr_matrix), intent(in) :: a

    Nonempty finite CSR matrix with unique columns within each row. Rectangular matrices are allowed here; GMRES requires square ones.

    Return Value type(csr_operator)

    New operator owning a deep copy of A. Invalid storage uses ERROR STOP with the status returned by VALIDATE_CSR_STORAGE.
