type, public, extends(matrix_factorization) :: sparse_lu_factorization

Owns a real CSR system and an ILUT preconditioner. SOLVE and SOLVE_IN_PLACE solve the original A * X = B using restarted GMRES; they do not merely apply the incomplete factors. This is an iterative solver, not a pivoted sparse direct LU factorization. FACTOR prepares the preconditioner explicitly, or solves prepare it lazily. UPDATE invalidates it. No dense matrix copy is formed. Errors return through optional FLAG arguments; if omitted, errors terminate with ERROR STOP. No inverse or determinant is provided.

    Constructs a sparse solver. The matrix and controls are stored without factorization; FACTOR or the first solve validates them.

    Arguments

    Type IntentOptional Attributes Name
    class(csr_matrix), intent(in) :: a

    Coefficient matrix to copy. Solving requires valid nonempty square CSR storage with unique column indices within each row.
    real(kind=real64), intent(in), optional :: droptol

    Finite nonnegative ILUT drop threshold; default SQRT(EPSILON).
    real(kind=real64), intent(in), optional :: tol

    Finite relative true-residual tolerance, at least EPSILON; default SQRT(EPSILON). Independent of DROPTOL.
    integer, intent(in), optional :: maxits

    Positive GMRES iteration budget, default 100. Checked at restart boundaries, so up to IM-1 additional iterations may be performed.
    integer, intent(in), optional :: im

    Restart length in [1, MIN(N, 50)]; default MIN(N, 50).

    Return Value type(sparse_lu_factorization)

    New unfactored solver owning its own copy of A and the controls.
