type, public, extends(matrix_factorization) :: svd_factorization

A container for the singular value decomposition of a matrix and associated operations. The decomposition is . The solvers compute the minimum-norm least-squares solution using the Moore-Penrose pseudo-inverse , where singular values below a tolerance are treated as zero. Any matrix shape is supported.

    Solves the linear system where is a matrix defining multiple right-hand-side vectors. The solution is the minimum-norm least-squares solution computed with the Moore-Penrose pseudo-inverse. Following the LAPACK DGELS convention, must have MAX(M, N) rows. The first M rows hold the right-hand-side on input, and the first N rows hold the solution on output.
