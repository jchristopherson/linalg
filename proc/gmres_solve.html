public subroutine gmres_solve(a, b, x, preconditioner, tol, atol, im, maxits, x0, flag, info)

Solves A*X=B with restarted GMRES and optional fixed right preconditioning. Only operator applications are requested; no entries or transpose are needed. All callbacks must represent fixed linear maps during a solve. Nonfinite callback outputs are rejected, but callbacks must manage their own failures because LINEAR_OPERATOR%APPLY has no status argument. The original residual is checked independently of SPARSKIT's estimates, including after a reported Arnoldi breakdown (which may be convergence). This routine is NOT reentrant because the bundled backend uses SAVE.

Arguments

Type IntentOptional Attributes Name
class(linear_operator), intent(in) :: a

Fixed real N-by-N operator, with N positive. APPLY and SIZE must not modify shared data or invoke this GMRES backend recursively.
real(kind=real64), intent(in) :: b(:)

Finite N-element RHS, preserved. Must not overlap X.
real(kind=real64), intent(out), allocatable :: x(:)

Allocated N-element solution on success, latest backend iterate on iteration/callback failure. Unallocated on input/allocation errors. An iterate returned with a nonzero FLAG must not be assumed accurate.
class(linear_operator), intent(in), optional :: preconditioner

Fixed N-by-N action Z=M*(-1)R for RIGHT preconditioning. It applies the approximate inverse, not M itself. Omit for no preconditioning. Variable/adaptive preconditioning requires a flexible method instead.
real(kind=real64), intent(in), optional :: tol

Finite RHS-relative tolerance in [0,1); default SQRT(EPSILON). Success requires NORM2(B-AX) <= TOLNORM2(B)+ATOL.
real(kind=real64), intent(in), optional :: atol

Finite nonnegative absolute residual tolerance, default zero. TOL and ATOL must not both be zero.
integer, intent(in), optional :: im

Restart length in [2,MAX(2,N)], default MAX(2,MIN(N,30)). There is no legacy PGMRES limit of 50. One is rejected because this backend silently replaces lengths <=1 with 15. Scalar systems use length 2.
integer, intent(in), optional :: maxits

Positive budget for backend-requested A products, default 300. Includes initial/restart residual products, not preconditioner calls or the wrapper's final residual check. Not a Krylov-step count.
real(kind=real64), intent(in), optional :: x0(:)

Finite N-element initial guess, preserved. Must not overlap X. Omit for zero.
integer, intent(out), optional :: flag

LA_NO_ERROR on verified convergence; LA_INVALID_INPUT_ERROR for invalid controls, empty dimensions, or nonfinite B/X0; LA_MATRIX_NOT_SQUARE_ERROR or LA_MATRIX_DIMENSION_ERROR for shapes; LA_OUT_OF_MEMORY_ERROR for allocation or 32-bit workspace overflow; LA_INVALID_OPERATION_ERROR for unexpected requests/nonfinite outputs; LA_CONVERGENCE_ERROR for budget, breakdown, or residual failure. Omit to use ERROR STOP on error, even if INFO is present.
type(iterative_solver_info), intent(out), optional :: info

Diagnostics, reset and populated even when a supplied FLAG reports failure. Counts include only callbacks that were actually performed.
