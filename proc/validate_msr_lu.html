public pure function validate_msr_lu(lu, ju) result(flag)

Validates the combined MSR triangular factors consumed by LUSOL. The diagonal contains inverse U pivots, not the original U diagonal. The unused value at N+1 and unused trailing capacity are not inspected.

Arguments

Type IntentOptional Attributes Name
class(msr_matrix), intent(in) :: lu

Nonempty square factors with row pointers in INDICES(1:N+1), followed by lower entries and then upper entries within each row.
integer, intent(in) :: ju(:)

N pointers splitting each row into its strict lower and upper parts.

Return Value integer

LA_NO_ERROR on success; LA_NOT_INITIALIZED_ERROR for missing arrays; LA_MATRIX_NOT_SQUARE_ERROR or LA_MATRIX_DIMENSION_ERROR for sizes; LA_INVALID_INPUT_ERROR for empty factors; LA_MATRIX_FORMAT_ERROR for invalid pointers or nontriangular columns; or LA_SINGULAR_MATRIX_ERROR for zero inverse pivots/nonfinite factors.
