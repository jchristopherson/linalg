procedure, public :: update => cf_update

Updates the factorization.

  • private subroutine cf_update(this, a, upper, flag)

    Updates the cholesky_factorization object with a new matrix. The matrix is only stored, not factored; therefore a call to factor is still required.

    Arguments

    Type IntentOptional Attributes Name
    class(cholesky_factorization), intent(inout) :: this

    The cholesky_factorization object.
    real(kind=real64), intent(in), dimension(:,:) :: a

    The matrix to factor. A copy of this matrix is made and stored by the object; therefore, this matrix is not altered. Also, any existing factorization is destroyed by this routine.
    logical, intent(in), optional :: upper

    Set to true if the upper factorization is to be computed (); else, set to false to compute the lower factorization (). The default is true such that the upper factorization is computed.
    integer, intent(out), optional :: flag

    An error flag.
