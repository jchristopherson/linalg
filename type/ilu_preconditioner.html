type, public, extends(linear_operator) :: ilu_preconditioner

Fixed approximate inverse backed by prepared ILUT triangular factors. This applies M**(-1), not the original matrix or a full GMRES solve. Constructor copies factors and pointers; applications use local output.


Constructor

public interface ilu_preconditioner

Constructs an owned approximate-inverse operator from ILUT factors.

  • private pure function ilu_op_init(lu, ju) result(rst)

    Copies precomputed ILUT factors and upper-row pointers; no setup occurs during APPLY. Factors can come from LU_FACTOR or GET_FACTORED_FORM.

    Arguments

    Type IntentOptional Attributes Name
    class(msr_matrix), intent(in) :: lu

    Nonempty finite square MSR factors, with inverse upper pivots.
    integer, intent(in) :: ju(:)

    N pointers to the upper parts of the factor rows.

    Return Value type(ilu_preconditioner)

    New fixed approximate-inverse operator owning independent copies. Invalid factors use ERROR STOP with VALIDATE_MSR_LU's status.
