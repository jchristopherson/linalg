type, public, abstract :: linear_operator

Defines a real-valued, possibly rectangular matrix-free operator. Concurrent applications require read-only operator data and separate output and scratch storage for each call. INTENT(IN) alone does not guarantee thread safety for pointer targets or external libraries.

procedure(apply_linear_operator), public, deferred, pass :: apply

Applies the linear operator.

  • subroutine apply_linear_operator(this, x, y) Prototype

    Computes Y = A * X without allocating the output vector. X and Y must have SIZE(2) and SIZE(1) elements, respectively, and must not overlap. Any scratch storage must be call-local.

    Arguments

    Type IntentOptional Attributes Name
    class(linear_operator), intent(in) :: this

    The [[linear_operator]] object.
    real(kind=real64), intent(in), dimension(:) :: x

    The input vector, with THIS%SIZE(2) elements.
    real(kind=real64), intent(out), dimension(:) :: y

    Caller-owned output, with THIS%SIZE(1) elements. All elements must be assigned, without reading previous values.
