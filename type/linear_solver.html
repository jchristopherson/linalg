type, public, abstract :: linear_solver

Defines a prepared solver for a square real-valued system. Preparation and factorization take place outside SOLVE. Each call must own its scratch storage to permit concurrent applications.

    Queries the dimensions of the prepared coefficient matrix.

    Arguments

    Type IntentOptional Attributes Name
    class(linear_solver), intent(in) :: this

    The prepared linear solver, which is not modified.
    integer, intent(in) :: dim

    The dimension to query: 1 for rows, 2 for columns.

procedure(solve_linear_system), public, deferred, pass :: solve

Solves the prepared system without modifying the solver.

  • subroutine solve_linear_system(this, rhs, x) Prototype

    Solves C * X = RHS for the prepared coefficient matrix C. RHS and X must have SIZE(1) and SIZE(2) elements, respectively, and must not overlap. Inner solves must be accurate enough for the outer iteration; a preconditioner alone is not sufficient.

    Arguments

    Type IntentOptional Attributes Name
    class(linear_solver), intent(in) :: this

    The prepared solver. Coefficients and factors are read-only; implementations must not hide mutable shared scratch state.
    real(kind=real64), intent(in) :: rhs(:)

    Right-hand side, with THIS%SIZE(1) elements.
    real(kind=real64), intent(out) :: x(:)

    Caller-owned solution, with THIS%SIZE(2) elements. All elements must be assigned before returning.
