generic, public :: solve_in_place => solve_multiple_rhs_in_place, solve_single_rhs_in_place

Solves the factored system with multiple right-hand-side vectors where the right-hand-side argument as a container for the result.

  • private subroutine qrf_solve_multiple_rhs_in_place(this, b, flag)

    Solves the linear system where is a matrix defining multiple right-hand-side vectors. The solution is returned in the first N rows of B, which must have MAX(M,N) rows. Underdetermined systems require column pivoting.

    Arguments

    Type IntentOptional Attributes Name
    class(qr_factorization), intent(inout) :: this

    The qr_factorization object.
    real(kind=real64), intent(inout), dimension(:,:) :: b

    On input, the M-by-NRHS right-hand side occupies the first M rows. On output, the N-by-NRHS solution occupies the first N rows.
    integer, intent(out), optional :: flag

    An error flag.

  • private subroutine qrf_solve_single_rhs_in_place(this, b, flag)

    Solves the linear system where is a matrix defining a single right-hand-side vector. The solution is returned in the first N elements of B, which must have MAX(M,N) elements. Underdetermined systems require column pivoting.

    Arguments

    Type IntentOptional Attributes Name
    class(qr_factorization), intent(inout) :: this

    The qr_factorization object.
    real(kind=real64), intent(inout), dimension(:) :: b

    On input, the M-element right-hand side. On output, the N-element solution occupies the first N elements.
    integer, intent(out), optional :: flag

    An error flag.
