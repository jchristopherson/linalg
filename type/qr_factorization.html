type, public, extends(matrix_factorization) :: qr_factorization

A container for QR factorization of a matrix and associated operations.


Constructor

public interface qr_factorization

    Initializes a new qr_factorization object.

    Arguments

    Type IntentOptional Attributes Name
    real(kind=real64), intent(in), dimension(:,:) :: a

    The matrix to factor. A copy of this matrix is made and stored by this object; therefore, this matrix is not altered.
    logical, intent(in), optional :: pvt

    An optional parameter that, if set to true, enables column pivoting. The default is false such that no column pivoting will be utilized.

procedure, public :: update => qrf_update

Updates the factorization.

  • private subroutine qrf_update(this, a, pvt)

    Updates the qr_factorization object with a new matrix. The matrix is only stored, not factored; therefore a call to factor is still required.

    Arguments

    Type IntentOptional Attributes Name
    class(qr_factorization), intent(inout) :: this

    The qr_factorization object.
    real(kind=real64), intent(in), dimension(:,:) :: a

    The matrix to factor. A copy of this matrix is made and stored by the object; therefore, this matrix is not altered. Also, any existing factorization is destroyed by this routine.
    logical, intent(in), optional :: pvt

    An optional parameter that, if set to true, enables column pivoting. The default is false such that no column pivoting will be utilized.
